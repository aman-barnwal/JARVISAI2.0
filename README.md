# 🧠 JARVIS AI

An advanced AI-powered assistant built with **Flask**, capable of performing multiple real-world tasks like Wikipedia search, Google lookup, Grammar check, Stock updates, QR code generation, News summaries, and more — all in one place!

---

## 🚀 Features

- 🌐 Google and YouTube Search  
- 🧮 Mathematics Solver (powered by Sympy)  
- 🧾 Grammar Checker  
- 📚 Free E-book Search  
- 📷 QR Code Generator  
- 🚄 Train & Flight Information  
- 📈 Stock Market Updates  
- 📰 Daily News Fetcher  
- ✅ Task Manager  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS (Beautiful UI)
- **Backend:** Python (Flask)
- **APIs:** Wikipedia, Requests, YFinance, Feedparser, etc.
